# Upstream-inherited docs

The files in this directory describe **upstream** [`google-ai-edge/gallery`](https://github.com/google-ai-edge/gallery) features and policies, preserved here as part of the Apache 2.0 attribution. They do **not** describe Gratitude-specific work.

| File | What it covers |
|---|---|
| [Bug_Reporting_Guide.md](Bug_Reporting_Guide.md) | How to capture a full Android bug report for the upstream Gallery app. The bug-reporting steps are valid for this fork too, but Gratitude-specific issues should be filed against this repo, not upstream. |
| [Function_Calling_Guide.md](Function_Calling_Guide.md) | Upstream's guide to fine-tuning custom function-calling models with the Gallery app. Not used by Gratitude — the community-* skills rely on prompting, not fine-tuning. |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Upstream's contribution policy ("not currently ready for code contributions"). This applies to upstream; Gratitude is a hackathon submission and is not currently accepting external contributions either. |

For Gratitude-specific docs, see the top-level [README.md](../../README.md), [backend/README.md](../../backend/README.md), and the SKILL.md files under [`Android/src/app/src/main/assets/skills/community-*`](../../Android/src/app/src/main/assets/skills/).
